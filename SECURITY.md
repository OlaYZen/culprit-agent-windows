# Security Policy

`culprit-agent` is the deployable agent for
[culprit](https://github.com/OlaYZen/culprit). Security is handled centrally in
the main repository.

## Reporting a vulnerability

**Please report security issues privately, never in a public issue or pull
request.** Use GitHub's private vulnerability reporting on the main repository:

- <https://github.com/OlaYZen/culprit/security/advisories/new>

The full policy, including what to include, our response targets, and scope, is
here:

- <https://github.com/OlaYZen/culprit/security/policy>

Issues that are specific to the agent (the bundled package, the Docker image, or
deployment) are welcome as normal, non-security issues on this repository.
